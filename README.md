**Overview**

A PostgreSQL database to catalog and manage information about celestial bodies such as planets, moons, and stars.

**Features**

    • Organized data schema for celestial classification
    • Supports queries for detailed celestial body information
    • Designed for astrophysics and research purposes
    
**Setup Instructions**

_Clone the repository:_

    git clone https://github.com/magwach/celestial_bodies.git 
    
_Import the database schema into PostgreSQL._

_Query the database for celestial body details._
